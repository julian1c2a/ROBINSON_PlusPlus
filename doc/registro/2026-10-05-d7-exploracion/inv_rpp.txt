## 2. The definitional chain after D7: names kept, values unchanged

```lean
-- Minimal/Axioms.lean
def succ_sym : List Char := ['σ']   -- … the 17 *_sym defs, same code points
def strCodeM (s : List Char) : Term := charsCodeM s
def codeNatStr (s : List Char) : Nat := codeNatChars s
theorem liftTerm_strCodeM (c : Nat) (s : List Char) : … := liftTerm_charsCodeM c s
theorem substTerm_strCodeM (v : Nat) (s : Term) (str : List Char) : … := substTerm_charsCodeM v s str
-- Meta/Provability.lean
def strCode (s : List Char) : Term := charsCode s
theorem strCode_injective {s t : List Char} (h : strCode s = strCode t) : s = t := charsCode_injective h
-- Meta/Representability.lean
theorem strCodeM_eq (s : List Char) : strCodeM s = strCode s := charsCodeM_eq s
-- Meta/CodeNumeralPrf.lean
theorem prf_strCode_numeral (s : List Char) : … := prf_charsCode_numeral s
-- Meta/DerivCondPrf.lean
theorem liftTerm_strCode (c) (s : List Char) : … := liftTerm_charsCode c s
theorem substTerm_strCode (v) (s : Term) (str : List Char) : … := substTerm_charsCode v s str
-- Meta/CodeNatInjPrf.lean
theorem codeNatStr_inj {s t : List Char} (h : codeNatStr s = codeNatStr t) : s = t := codeNatChars_inj h
-- Meta/CodeDecode.lean
def decodeStr (c : Term) : Option (List Char) := decodeChars c
theorem decodeStr_strCodeM (s : List Char) : decodeStr (strCodeM s) = some s := decodeChars_charsCodeM s
theorem decodeStr_inj {c : Term} {s : List Char} (h : decodeStr c = some s) : c = strCodeM s := decodeChars_inj h
-- Meta/ModeloEstandar.lean
theorem ev_strCodeM (v) (s : List Char) : … := ev_charsCodeM v s
-- Meta/SolidezVerificador.lean
def decS (n : Nat) : List Char := (decodeL n).map Char.ofNat
def dflt : Term := Term.func [] []
theorem decS_codeNatStr (s : List Char) : decS (codeNatStr s) = s := by
  rw [decS, codeNatStr, decodeL_codeNatChars, List.map_map]
  have e : (Char.ofNat ∘ Char.toNat) = id := funext Char.ofNat_toNat
  rw [e, List.map_id]
```

**Why the values do not change.** Each literal `L` becomes `L.toList`. The new `strCodeM (L.toList)` unfolds to `charsCodeM L.toList`, which is exactly what the old `strCodeM L` unfolded to. The same holds for `strCode` and `codeNatStr`.
- So `codeNatTerm`, `codeNat`, `tcFnN`, `V₀`, the anchor and `godelCN` keep the same natural-number values.
- The code `Term`s correspond to the old ones through `toList`.
- `""` maps to `[]` (`dflt`).
- All of this holds only if the code points are transcribed exactly.

Keep these as plain `def`, not `abbrev`, so `simp` and `rw` keys stay as they are. This is an ESTIMATE of the safer choice.

The toolchain has the helpers it needs (`Lean.Syntax.mkCharLit` at `Init/Meta/Defs.lean:860`, `TSyntax.getString` at 1347). It must live in a module that `Axioms.lean` imports. ESTIMATE, untested.
